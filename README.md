# Dani Systems — Платформа 1С:Фреш, АУСН и диспетчеризации заявок

Веб-портал и CRM-система для подключения малого бизнеса и ИП на АУСН к облачному сервису 1С:Фреш, управления пакетами часов и распределения задач между независимыми специалистами (партнёрами).

## Основные возможности
* **Витрина и приём обращений:** Адаптивный интерфейс в стиле DarkIce, тарифные пакеты («Старт», «Комфорт», пакеты консультаций), AJAX-отправка заявок с мгновенными уведомлениями в мессенджер MAX.
* **Личный кабинет клиента (`/cabinet/`):** Создание обращений в поддержку, отслеживание статусов и контроль остатка минут в пакете.
* **Кабинет партнёра (`/partner/`):** Взятие заявок в работу, учёт затраченного времени, сдача задач на проверку и регистрация с обязательным акцептом партнёрской оферты (80/20, ИП и самозанятые).
* **Панель управления (`/manage/`):** Назначение исполнителей, проверка выполненных задач, возврат на доработку с комментариями и списание пакетных минут.
* **Блог и портал «Телепорт» (`/blog/`, `/teleport/`):** Публикация экспертных статей по 1С и АУСН, а также развлекательный IT-раздел.
* **Безопасность и DevOps:** Соответствие требованиям 152-ФЗ во всех формах, хранение секретов и реквизитов через `.env`, автоматический CI/CD деплой через GitHub Actions.

## Быстрый старт (локально)

```bash
git clone https://github.com
cd dani_systems
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```
